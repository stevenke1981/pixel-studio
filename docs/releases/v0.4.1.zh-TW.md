# Pixel Studio v0.4.1

本版整合 v0.4 的編輯資料保護修正，新增自動／手動打碼框的單框選取與刪除。
沿用 Rust + Slint，不合併來源未辨識的 Grok 歷史分支。使用者已批准發行；
下列尚未完成的原生互動驗收限制仍然保留。

## 更新內容

- 點框或清單文字選取單一打碼框；Delete／Backspace、框上右鍵或該列垃圾桶只移除該框。支援 Ctrl+Z 復原及 Ctrl+Y 重做，保留其他框與勾選狀態。
- 單框編輯目標與套用勾選分開；刪除最後一框後連按 Delete 不會轉而刪除圖層或像素。文字欄位及對話框中的 Delete 不轉送刪框。
- 框內容改變或正在拖曳時拒收舊 OCR 結果，避免已刪除的框被帶回。
- 新建、替換及關閉前檢查未儲存修改；專案儲存與平面匯出狀態分離。
- 圖片、專案及 C2PA 先完成暫存再原子替換，寫入失敗保留既有輸出。
- 修正手勢取消、方向鍵撤銷、文字編輯分組與含圖層圖片變換；補齊可拖曳物件的手掌、抓握及縮放游標。
- Windows 安裝器不再強制終止 App。發布流程保留既有 Release／附件，新版附件核對完成後才公開。

## 使用方式

1. Windows 可使用安裝包，或完整解壓 portable ZIP 後執行 `pixel-studio.exe`；請保留旁邊的 `models` 資料夾。
2. 開啟圖片，切到「自動打碼」，按「偵測文字」。用打碼框工具在空白處拖曳可新增手動框。
3. 點框或清單文字，橘框表示目前編輯目標。按 Delete／Backspace、右鍵或該列垃圾桶刪除；Ctrl+Z 復原，Ctrl+Y 重做。
4. 清單勾選決定哪些框會套用。確認範圍及打碼方式，按「套用打碼」，再儲存或匯出；小視窗需向下捲動側欄才能看到套用按鈕。

## 驗證範圍與已知限制

- 已有核心、Slint testing backend、離線 OCR 與輸出像素回歸測試，獨立程式審查，以及 Windows／Linux 真實 App 截圖證據。正式版的建置、測試與套件驗證以本 tag 的 CI 及隨附 SHA256 為準。
- **新增功能的 Windows 原生滑鼠／鍵盤互動、GUI 套用→匯出→重開及不同 DPI 尚未完整驗收**。執行環境缺少原生桌面輸入工具；發行批准不代表這些測試通過。原生文字輸入法、捲動及未儲存視窗狀態升級也未驗收。
- 打碼框是預覽，既有專案格式不保存這些框；請先套用再儲存。刪除預覽框不會移除已套用到圖片像素的打碼。
- OCR 可能辨識錯誤，需自行確認。丟棄過期辨識結果不會強制停止正在運算的 OCR 執行緒。
- Windows 小工作區的框清單與側欄各自可捲動；套用按鈕可能不在初始可見區。較大圖片在目前縮放比例下可超出畫布 viewport。
- Linux 以 CI 與 Xvfb App 截圖驗證；macOS 為 Intel／Apple Silicon universal，沒有實機 GUI 驗收。macOS `.app` 採 ad-hoc 簽署，未公證；說明文件另附於 universal tar.gz。請勿為安裝而關閉系統安全設定。
