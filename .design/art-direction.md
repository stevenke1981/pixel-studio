# Pixel Studio Art Direction

## Intent

Pixel Studio should feel like a bright Windows productivity tool for the focused journey:
capture or open, annotate, protect private information, crop, then save a new file. Every
important action must be readable without guessing an icon or opening a menu.

## Focused Productivity recipe

- Light canvas workspace with white surfaces, dark text and one Windows-blue accent.
- High-contrast borders separate the two-row command/tool bar, canvas, inspector and status bar.
- Text labels remain visible beside compact symbols; core actions are never icon-only.
- Primary controls are 38–42 px high with a consistent 8 px spacing rhythm.
- Selected tools use a pale-blue fill, blue border and dark-blue text.
- Disabled actions stay legible but visibly unavailable.
- Restrained 5–6 px corner radius keeps the interface native and practical.

## Interaction rules

- Capture, open, paste and save are always visible in the command bar.
- Annotation tools live in one top strip and show V/C/T/L/A/R/H shortcuts.
- Clear canvas is a visible top-row action and remains reversible from the Project menu.
- Image metadata, C2PA details and folder navigation live in a top menu instead of reserving a rail.
- Privacy actions are full-width buttons instead of a compressed row.
- The inspector follows the task order: workflow hint, blur/privacy/export, crop, layers.
- Advanced features remain discoverable without crowding the default quick workspace.
- Mouse-wheel zoom and middle-button pan remain native canvas interactions.
