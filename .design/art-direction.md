# Pixel Studio Art Direction

## Intent

Pixel Studio should feel like a focused desktop capture editor, not a settings dashboard.
The primary journey is capture or open, annotate, protect private information, crop, then save a
new file.

## Studio Neutral recipe

- Dark neutral canvas workspace with a single violet accent.
- Dense but readable desktop controls; 32–36 px primary control height.
- Open rails and panels instead of a card around every control.
- Explicit text labels for tools; no ambiguous icon-only actions.
- Strong hierarchy: command bar, tool rail, canvas, inspector and status bar.
- Consistent 8 px spacing rhythm and restrained corner radius.
- Clear hover, selected, disabled and keyboard-focus states.

## Interaction rules

- The command bar contains only file, history, workspace and zoom actions.
- Annotation tools live in one vertical rail and show their keyboard shortcut.
- The inspector follows the task order: workflow hint, privacy/export, crop, layers.
- Advanced features remain discoverable without crowding the default quick workspace.
- Mouse wheel zoom and middle-button pan remain native canvas interactions.
